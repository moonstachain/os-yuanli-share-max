# profile / content

**目标**：把 OS-原力 kernel + 作者的内容生产能力栈给学员装好。

## 装什么

基于 `lite` + 四组：

1. **切角体系**（5 种 `angle-*`）
   - `angle-business-model` / `angle-founder-story` / `angle-qianshenjinshi` / `angle-truth-flip` / `angle-user-introspection`
2. **内容引擎**
   - `ai-viral-content-engine` / `ai-visual-production-planner` / `ai-brand-positioning`
3. **文风与品质**
   - `xiaociwei-writing-style` / `wechat-writer` / `doc-standard`
4. **跨平台分发**
   - `agent-reach`

## 已内建的质量门

卫星 skill 里的 `content-quality-gate` 会在 `full mode` 的 Publish Pack 步骤自动触发，拦截"还没到洞察层"的稿子。

## 一键安装

```bash
bin/os-yuanli-install-profile --profile content
```
