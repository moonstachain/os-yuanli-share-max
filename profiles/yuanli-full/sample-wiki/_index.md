# Wiki · Index

这是一份**脱敏样例**。学员装完 `yuanli-full` profile 后，用它作为起点养自己的 Wiki。

## Layer 1 · Sources（只读）

- [articles/](sources/articles/) — 剪藏文章
- [papers/](sources/papers/) — 论文
- [books/](sources/books/) — 书摘
- [transcripts/](sources/transcripts/) — 谈话/视频转录

## Layer 3 · Insights（人类专属）

- [insights/](insights/) — 个人立场、反思、决策

## Layer 4 · Metabolism

- [_factory/](_factory/) — 内容工厂
- [_staging/](_staging/) — 待审核
- [_feedback/](_feedback/) — 反馈区

## 宪法

见 [_schema.md](_schema.md)。任何 Wiki 操作前必须先读。

## Bootstrap 建议

1. 先删除本 `_index.md` 里你不需要的分类
2. 把自己已有的 Markdown 笔记按 4-layer 归位
3. 跑 `knowledge-liming` 的 `/knowledge-liming "<topic>"` 验证能读到
4. 在 `insights/` 下写第一条属于你自己的判断
