# profile / governance

**目标**：把"skill 如何被孵化 → 审计 → 发布 → 回收"的治理基础设施装给学员。

## 装什么

基于 `lite` +：

- **孵化**：`skill-creator` / `auto-skill` / `auto-skill-extraction-sqlite`
- **审计**：`skill-audit` / `github-skill-naming-audit` / `wiki-lint`
- **发布**：`skill-pattern-publisher`
- **演化**：`skill-trainer-recursive` / `self-evolution-max` / `skill-bandit`
- **协作**：`collab-sync`

## 与其他档的关系

- `engineer` 档让你**写业务代码**
- `governance` 档让你**写"让业务代码被写出来的基础设施"**
- 两档可并存

## 一键安装

```bash
bin/os-yuanli-install-profile --profile governance
```
