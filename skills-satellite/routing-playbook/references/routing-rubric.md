# Routing Rubric

Use only these five criteria when comparing candidate skill chains.

## 1. 任务适配度

Does the chain directly match the real job, not just a keyword in the prompt?

## 2. 验真清晰度

Can the chain state a concrete minimum verification target before execution?

## 3. 人类打扰成本

Does the chain minimize unnecessary user interruption while still respecting human-only boundaries?

## 4. 边界稳定性

Can the chain clearly explain why nearby alternatives are worse for this task?

## 5. 组合复杂度

Is this the smallest sufficient chain, rather than an impressive but bloated stack?

## Decision Rule

Prefer the smallest chain that wins on fit and verification.

Do not add a third skill unless it changes the result quality, verification path, or human interruption cost in a material way.
