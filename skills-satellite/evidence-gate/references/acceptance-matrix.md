# Acceptance Matrix

Use both layers for every acceptance decision:

1. artifact or state exists
2. artifact or state matches the intended goal

## Reports

- artifact check: file exists and opens
- goal check: required sections exist and sampled content matches task objective

## Screenshots

- artifact check: image exists and is readable
- goal check: visible state matches the intended page, app, or region

## Data Exports

- artifact check: file or dataset exists
- goal check: schema, counts, and samples match requested scope

## Automation Outcomes

- artifact check: action completed or receipt exists
- goal check: final state confirms the intended effect

## External Writes

- artifact check: remote write returned success
- goal check: follow-up read confirms the exact intended state
