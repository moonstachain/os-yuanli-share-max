# 四层渐进式内容质检

> **设计理念**
> 借鉴软件工程测试金字塔，从最基础的硬性规则到最主观的人格判断，层层递进。
> 四层全部通过，内容才算达标。蒸馏自数字生命卡兹克的四层自检体系。

---

## 使用方式

### 独立使用

```
/content-quality-gate [文章路径或内容]
```

### 被其他 skill 调用

在其他 skill 的质检环节，指示 Agent：

> 调用 content-quality-gate skill，对当前内容执行 L1-L4 四层质检。
> 可选参数：
> - `--level L1-L2`：只跑硬性规则和风格检查（快速模式）
> - `--profile strict`：严格模式，L2 口语化要求翻倍
> - `--profile report`：报告模式，放松标点禁令（允许冒号和破折号）
> - `--skip L3-5`：跳过文章类型专项检查（非五种标准原型时）

---

## L1 硬性规则检查（自动扫描层）

类似代码的语法检查。任何一项不通过就必须修复，没有例外。

### L1-1 禁用词扫描

全文搜索以下词汇，出现则必须替换：

| 禁用词 | 替换建议 |
|-------|---------|
| 说白了 | 坦率的讲、其实就是 |
| 意味着什么 / 这意味着 | 那结果会怎样呢、所以呢 |
| 本质上 | 说到底、其实 |
| 换句话说 | 你想想看、也就是说 |
| 不可否认 | 直接删掉，换成正面陈述 |
| 综上所述 / 总的来说 | 换成具体的回扣句 |
| 首先...其次...最后 | 用自然的转场词替代 |
| 值得注意的是 / 不难发现 | 删掉，直接说 |

### L1-2 禁用标点扫描

> **注意**：在 `--profile report` 模式下，本项跳过（报告类内容允许冒号和破折号）。

| 禁用标点 | 替换 |
|---------|------|
| 冒号 ： | 用逗号替代 |
| 破折号 —— | 用逗号或句号替代 |
| 双引号 "" 或 "" | 用「」替代，或不加引号 |

### L1-3 结构性套话扫描

检查是否出现以下模式：
- 「让我们来看看...」「接下来让我们...」
- 「在当今...的时代」「随着...的发展」
- 连续使用 bullet point 罗列观点（超过 3 个需改成散文叙述）
- 大段加粗（超过 2 行的加粗几乎肯定是过度结构化）

### L1-4 工具名检查

确认所有提到的 AI 工具/产品都使用了具体名称，没有出现「AI工具」「某个模型」「相关技术」等空泛表述。

**通过标准**：以上四项扫描零命中。

---

## L2 风格一致性检查（模式匹配层）

类似代码的单元测试。每一项给出「是/否」判断。

### L2-1 开头检查
- 是否从一个具体的、当下的事件/场景切入？（不是宏大叙事）
- 第一句话是否让读者产生「然后呢？」的冲动？
- 有没有使用任何教科书式开头？

### L2-2 节奏与结构检查
- 是否有长短句交替？（连续 3 句以上句式长度相近 = 节奏呆板）
- 是否有一句话独立成段的「断裂」效果？（全文至少 3 次）
- 偏离主线的段落后面是否有「扣主线句」拉回来？
- 有没有用疑问句来制造节奏的刹车和转向？

### L2-3 口语化检查
- 全文是否出现 8-10 个不同的口语化表达？
- 有没有论述中的故意打破？（重复强调、中途打断、省略主语等）
- 有没有至少一处自嘲或承认不足？

**推荐口语化词组**：

| 用途 | 词组 |
|------|------|
| 转场 | 坦率的讲、说真的、其实吧、你想想看、我跟你说、回到xxx这块 |
| 判断 | 我一直觉得、我自己的感受是、不是说xxx不行而是说 |
| 自嘲 | 说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟 |
| 情绪 | 这种感觉太爽了、我当时就愣住了、想想就觉得兴奋 |
| 拉近 | 很多朋友可能不知道、你如果关注这个领域的话 |

### L2-4 标点禁令二次确认
- 全文是否完全没有冒号、破折号和双引号？（AI 容易在修改过程中重新引入）
- `--profile report` 模式下跳过此项。

**通过标准**：L2-1 全部通过，L2-2 至少 3/4 通过，L2-3 至少 3/4 通过，L2-4 通过。

---

## L3 内容质量检查（深度审查层）

类似代码的集成测试。

### L3-1 观点支撑检查
- 每个核心观点是否都有具体的人/场景/细节/数据支撑？
- 有没有空泛的观点只有论断没有例证？

### L3-2 知识输出方式检查
- 知识点是否以「聊着聊着顺手掏出来」的方式呈现？
- 有没有出现「下面我来介绍」「首先需要了解」这种教科书式科普？
- 引用是否自然融入论述，像「聊着聊着想起来的」而不是「我特意去查的」？

### L3-3 文化升维检查
- 有没有至少一处从具体事件连接到更大的文化/哲学/历史参照物？
- 这个连接是否自然？（不是硬凑的升华）

### L3-4 对立面与同理心检查
- 在讲核心观点时，是否有对对方立场的理解和承认？
- 有没有先站到读者的处境里，再给出自己的视角？

### L3-5 文章类型专项检查

> 仅适用于公众号文章。研究报告类内容可跳过或用 `--skip L3-5`。

根据文章原型做针对性检查：
- **调查实验型** -> 有没有「亲自下场」的叙事感？过程是否有层层递进？
- **产品体验型** -> 有没有真实使用场景？有没有自然的竞品对比？
- **现象解读型** -> 是否有「观察->好奇->研究->升维」的推进？
- **工具分享型** -> 有没有个人故事铺垫？效果展示是否让人惊叹？
- **方法论分享型** -> 每节是否有可执行动作？是否坦诚说明学习成本？

### L3-6 逐一展示检查
- 如果涉及多个产品/案例的比较，是不是用了逐一展示（每个带吐槽点评）而不是一次性罗列？

**通过标准**：L3-1 和 L3-2 必须全部通过，L3-3 至 L3-6 中至少通过相关项。

---

## L4 活人感终审（最终人格层）

最重要也最主观的一层。以读者视角通读全文，回答一个核心问题：

> **「读完这篇文章，我感觉是一个有见识的真人在认真跟我聊一件打动他的事，还是一个 AI 在给我输出信息？」**

### L4-1 温度感
- 情绪表达是体感记忆（「我当时就愣住了」「鼻子一酸」）还是知识性描述（「我感到非常震撼」）？
- 人物描写是否让你「能感觉到他的体温」？

### L4-2 独特性
- 这篇文章是否有「只有这个作者才会写出来的角度」？
- 还是换一个 AI 博主也能写出差不多的东西？

### L4-3 姿态检查
- 语气是不是「一个有见识的普通人在认真聊一件打动他的事」？
- 有没有不自觉地滑入了「导师在教学生」或「品牌在做营销」的姿态？

### L4-4 心流检查
- 从头到尾读，有没有哪个地方注意力断掉了？需要回头理解逻辑？
- 如果有，那个地方就是需要修复的节奏问题。

**通过标准**：L4-1 到 L4-4 整体感觉「这像是真人写的」。如果任何一项让你觉得「这段 AI 味太重了」，就需要返工。

## Profile 模式说明

| Profile | 适用场景 | L1-2 标点禁令 | L2-3 口语化要求 | L3-5 类型专项 |
|---------|---------|--------------|----------------|--------------|
| `default` | 公众号文章 | 严格执行 | 8-10个 | 执行 |
| `strict` | 高标准公众号 | 严格执行 | 15-20个 | 执行 |
| `report` | 研究报告/白皮书 | 放松（允许冒号破折号） | 5-8个 | 跳过 |
| `marketing` | 营销文案 | 严格执行 | 8-10个 | 跳过 |
