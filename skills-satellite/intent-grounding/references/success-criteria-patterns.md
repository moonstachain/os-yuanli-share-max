# Success Criteria Patterns

## Vague ask: "帮我搞定"

Translate into:

- final artifact or state
- acceptable quality bar
- interruption boundary

## Vague ask: "帮我看看"

Translate into:

- whether this is diagnosis, summary, recommendation, or verification
- what evidence is required in the answer

## Vague ask: "做一个方案"

Translate into:

- whether the user wants plan only or immediate implementation
- what level of detail is needed
- how completion will be judged
