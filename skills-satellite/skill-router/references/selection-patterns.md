# Selection Patterns

## Prefer local repo facts

Use for:

- code questions
- file discovery
- config or schema inspection

## Prefer scripts or CLIs

Use for:

- deterministic transforms
- existing project automation
- authenticated toolchains already present locally

## Prefer APIs

Use for:

- stable external data access
- structured operations with reliable responses
- lower-fragility alternatives to UI automation

## Prefer domain skills

Use when the task matches a specialized local skill and that skill already encodes domain-specific heuristics.

## Prefer browser automation

Use only when the target system is UI-only, or when lighter programmatic paths cannot reach the needed state.
